# 🧠 MindTrack

### Privacy-First Student Wellbeing Early-Support Platform

## 📌 About the Project

MindTrack is a privacy-first student wellbeing platform designed to help students understand changes in their personal wellbeing patterns.

Students can record their mood, stress, sleep, study workload, and personal reflections through daily check-ins.

The system analyzes changes in the student's own historical pattern and provides supportive self-care suggestions and information about available support services.

MindTrack does not diagnose mental-health conditions.

---

## 🎯 Problem Statement

Students may experience academic pressure, workload changes, and changes in daily routines without recognizing when their wellbeing pattern has changed.

MindTrack helps students notice these changes earlier through personal wellbeing tracking and pattern analysis.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run the project using VS Code Live Server.
5. Click **Student Login**.
6. Enter the login details.
7. Open the dashboard and use the available features.

---

## 🔐 Privacy

MindTrack is designed with privacy in mind.

Wellbeing records are stored locally in the browser for this prototype.

The system does not diagnose mental-health conditions or replace professional support.
